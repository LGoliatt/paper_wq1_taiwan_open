# A comparative study of ensemble and non-ensemble machine learning methods for predicting river pollution index 


https://doi.org/10.1016/j.ecoinf.2026.103617

Open access under CC-BY 4.0.

## Overview
Predicts River Pollution Index (RPI) using Taiwan's 36-year river dataset. Compares ensembles (CatBoost, XGBoost, NGBoost) vs. non-ensembles (SVM, CNN). CatBoost achieves RMSE ~0.85, R²=0.78.[web:37]

## Features
- Ensemble models with ~20% error reduction over baselines.
- Bayesian optimization (Optuna) for hyperparams.
- 30-run stability analysis and cross-validation.
- SHAP for interpretability (add-on).
